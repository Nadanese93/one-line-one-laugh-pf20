An entry for the [make.fun](https://make.fun) bounty **One Line, One Laugh** (2 USD prize, top 10).

## The entry

> My lawyer bills in six-minute increments, so I now say hello in under thirty seconds to save money.

One funny line, 99 characters: a client so thrifty that even saying hello gets timed against the lawyer's six-minute billing increments.

## How it works

`main.py` writes the entry string to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`), with no trailing newline.
It validates the gate first: 1-200 characters, not only whitespace, one line.

Run it with:

```sh
python3 main.py
```
